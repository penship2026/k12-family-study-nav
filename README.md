# 起步线K12（原「小学家庭学习规划汇聚页」）（纯静态 · 方案 B）

只做「学习规划 + 资源导航 + 课程推荐 + 教材目录索引」，不上传、不托管课件、视频与教材正文；无后端、无数据库，双击即可离线打开。

## 页面结构

### 教材目录口径（textbooks.html）
教材的著作权与出版资质都在编写单位、出版单位一侧（教材多按法人作品 + 汇编作品保护，中小学教科书的出版发行另有资质限制），因此这一页**不做内容承载，只做结构化索引**，守住三条红线：

- **只展示目录结构**：单元名 / 章标题 / 起始页码 / 知识点条目名，**不复制正文、插图、习题原文**，也不做整本 PDF、扫描页、缩略图转载。
- **每个单元都跳官方**：右侧「官方电子教材」直达国家中小学智慧教育平台对应册次页面（`basic.smartedu.cn/tchMaterial/detail?...&contentId=<册次 id>`），正文一律到官方渠道看，本站不镜像。
- **布局**：不做下拉。顶部只放学段胶囊和搜索框，下面按学科折叠成组，组内按版本分块、块内是册次卡，一次点击即可跳官方；知道书名/年级的用户用搜索框一步到位。
- **封面口径**：语文 23 册（小学 12 + 初中 6 + 高中 5）、数学（小学）12 册、英语人教版（吴欣 / 苗兴伟）与外研社（刘兆义）三系列 22 册，共 **57 册**有封面；小学部分按「学科-年级-册次」命名，初中/高中按 contentId 定位（高中册次如「必修 上册」不规则，故用 cid 做键）。官方图片带 Referer 防盗链、单张 1.2 MB，不能外链，因此下载后压成 180–220 px 小图内嵌在 HTML 里；其余 1854 册只用文字卡。素材源图另存 `assets/covers/`（380 px）。
- **版本差异**：语文、道德与法治、历史、思想政治为全国统一统编版；数学 7 版、科学 8 版、英语（小学）23 版、音乐 15 版。同一出版社按主编分系列（如「人教版（主编：吴欣）」），与课本封面一致。
- **版本口径**：语文、道德与法治、历史、思想政治为全国统一统编版；数学 7 版、科学 8 版、英语（小学）23 版、音乐 15 版。同一出版社还会按主编分系列（如「人教版（主编：吴欣）」），与课本封面、版权页一致。
- **册次命名**：小学 / 初中按「年级 + 上册 / 下册 / 全一册」，高中按官方「必修 第 N 册 / 选择性必修 第 N 册」，小语种沿用 C1、G1、必修Ⅰ（上册）等原名。
- **数据来自官方公开接口**：册次清单与 contentId 取自平台 `data_version.json` 及 details 接口；单元与章节标题按平台公开目录页整理，页码为起始页，仅作定位参考。

页面顶部固定一条说明条，明示「教材著作权归编写单位与出版单位所有，完整内容请前往官方平台查看」，避免读者误以为是全文库。教案同理，如需扩展请只做「课名 + 对应教材单元 + 官方入口」的索引。

### 学科口径
- **课内 10 门**（依《义务教育课程方案（2022 年版）》小学段）：语文、数学、英语、科学、道德与法治、体育与健康、音乐、美术、劳动、信息科技。
- **课外 8 个模块**：书法、编程、大阅读、英语拓展、数学思维、戏曲、科技、体育运动。
- 同一学段（1–2 / 3–4 / 5–6）任务一致，年级差异体现在「本学期重点」；这样 18 科 × 3 学段 = 54 套任务即可覆盖 1–6 年级。
- 1–2 年级英语、科学（多数地区 3 年级起独立开课）、信息科技（3 年级起）在页面中明确标注"未开课/以渗透为主"，避免超前加码。

## 一、国家能力要求要点（standards.html · 1–12 年级）
小学、初中依据《义务教育课程方案和课程标准（2022 年版）》；高中依据《普通高中课程方案和课程标准（2017 年版 2020 年修订）》。要点如下：

- **三阶段结构**：小学 1–6 年级（义务教育 2022 版课标）、初中 7–9 年级（第四学段）、高中 10–12 年级（普通高中 2017 版 2020 修订，学分制）。
- **学段划分**：1–2 年级第一学段、3–4 第二学段、5–6 第三学段、7–9 第四学段；英语另设一级（3–4）、二级（5–6）、三级（7–9）。
- **高中核心数据**：必修 88 学分 + 选择性必修 ≥42 + 选修 ≥14 = 毕业最低 144 学分；18 课时 = 1 学分；学业质量分 5 级（水平 1–2 对应合格考、3–4 对应等级考、5 为选修）。
- **初中要点**：语文累计 3500 字、默读每分钟 ≥500 字、行楷；数学核心素养从"意识"升级为"能力/观念"（抽象、推理、数据观念、模型观念）；英语三级要求获取关键信息。
- **课时比例**：语文 20%–22%、数学 13%–15%、体育与健康 10%–11%、艺术 9%–11%、科学 8%–10%、外语 6%–8%、道德与法治 6%–8%、信息科技 1%–3%。周课时：低年级 26 节 / 中年级 30 节 / 初中 34 节。
- **语文硬指标**：1–2 年级认识 1600、会写 800；3–4 累计 2500 / 1600；5–6 累计 3000 / 2500；7–9 累计 3500。古诗文背诵 1–6 年级 75 篇、7–9 年级 60 篇。
- **数学**：小学核心素养 11 项（数感、量感、符号意识、运算能力、几何直观、空间观念、推理意识、数据意识、模型意识、应用意识、创新意识）；总目标为"三会"。
- **英语**：一级核心动作是"模仿 + 大声跟读"，不是背单词表；二级要求理解语调、听懂简单对话。
- **书法**：无独立学科，写字要求写在语文课标"识字与写字"里；3–6 年级语文课每周 1 课时书法课；毛笔从 3–4 年级临摹正楷字帖起步。
- **落地映射**：页面末尾把每条课标要求翻译成家庭动作，并对应到本站其他页面。

## 二、课程推荐要点（courses.html）
按 **课内 / 课外** 两个页签组织，课内 10 门一节不少，课外 8 个模块各成一块。

- **课内 · 语文**：国家平台同名教材同步微课做主线（只补"没听懂的那一课"），快乐读书吧跟学期；《日有所诵》做加餐。
- **课内 · 数学**：国家平台同步微课 + DK《图解数学》工具书 + ChinaTextbook 教材 PDF；口算/错题工具放到课外数学思维。
- **课内 · 英语**：教材音频"听—跟读—读一遍"+"一套分级读物"；拼读放到课外英语拓展，避免重复。
- **课内 · 科学**：国家平台科学微课（实验演示）+ 中国科技馆线上资源 + DK 百科；强调"猜想—做法—结果"三行记录。
- **课内 · 道德与法治**：教材情境 + "如果是你会怎么做、为什么"，每周 2 次、10 分钟，不背标准答案。
- **课内 · 体育与健康**：学校体育课 + 每天户外 1 小时；《国家学生体质健康标准》项目（跳绳、坐位体前屈、50 米等）每月自测。
- **课内 · 音乐 / 美术**：国家平台美育资源 + 故宫数字文物库看真迹；一件小乐器，不考级驱动。
- **课内 · 劳动**：课标 10 个任务群，家庭每学期做实 2 个（整理收纳、烹饪营养优先）。
- **课内 · 信息科技**：国家平台同步课 + Code.org 不插电活动（1–2 年级无课时正好用）。
- **课外 · 书法**：荆霄鹏《零基础学楷书》（B站，按偏旁挑着看）、童嘉优（教材同步）、毛笔楷书四家选一本临 3 个月。
- **课外 · 编程**：Scratch → micro:bit → Python 海龟绘图，每两周一个项目。
- **课外 · 大阅读**：亲近母语分级书目 + 国家智慧教育读书平台，配套国家书单。
- **课外 · 英语拓展**：Oxford Phonics World / Jolly Phonics 二选一 → RAZ 或牛津树；Oxford Owl、LearnEnglish Kids、Starfall 免费配套。
- **课外 · 数学思维**：Maths No Problem、Math Playground、`calc-master`、`wrong-notebook`；每周 2–3 道思维题封顶。
- **课外 · 戏曲**：央视网戏曲频道看整折戏，先武戏（《三岔口》）后文戏；脸谱用《京剧脸谱》（官方目录）入门，每月 1 折 + 1 张脸谱。
- **课外 · 科技**：中国数字科技馆「动手做」+ 中国科技馆实体馆（每学期 1 次）；器材顺序 纸电路（几十元）→ micro:bit（150–260 元）→ Arduino（5 年级起），每学期 1 个完整项目。
- **课外 · 体育运动**：学校体育课 + 体测项目（跳绳 / 坐位体前屈 / 50 米）+ 1 项主项（游泳、球类、田径、武术）；先保住每天户外 1 小时（近视防控要 2 小时光照）。
- **渠道态度**：官方/出版社/有署名正式课程优先；公众号、小红书、视频号只给检索关键词与甄别标准，不点名博主。

## 四、本地 ⇄ 云盘 同步（工作流）
本仓库是唯一的工作副本：**先改本地，再同步到云盘**。改完运行一个命令即可。

```bash
./sync.sh status   # 只看本地与云盘的差异
./sync.sh pull     # 云盘 -> 本地（别处改过云端时用）
./sync.sh push     # 本地 -> 云盘：只传 *.html 与 README.md，原地覆盖同名文件
```

- `push` 会先读云端 rel_path → file_token，按同名原地覆盖，不会在云盘产生重复文件；随后自动把 `README.md` 刷成在线文档。
- 云盘位置：飞书「想法创意 / 小学学习规划汇聚页」，folder_token `IESMf1R7PlhitZdvmSMcWpFunic`；在线文档 `https://my.feishu.cn/docx/N27Ad1yZDoROmLxRActc2qftnog`。
- 脚本只同步页面文件，自身和临时文件不会被上传。

## 五、如何维护内容
- **改年级规划/任务**：`index.html` 内 `PLAN` 对象（按 学科 → 学段 组织，`goal` 目标 / `daily` 建议时长 / `tasks` 任务清单），年级差异在 `GRADE` 的 `focus` 字段；新增学科需同时补 `IN_SUBJECTS` 或 `OUT_SUBJECTS` 与 `SUB_COLOR`。
- **改资源链接**：`index.html` 顶部 `RES` 对象；各学科用 `res:["资源id"]` 引用。
- **加/改课程**：`courses.html` 内 `K_*`（课内）与 `O_*`（课外）模板字符串，一个 `<div class="item">` 就是一条课程，标签用 `t-ch`（渠道）、`t-gr`（年级）、`t-free`/`t-paid`/`t-book`（性质）。
- **改书单**：`resources.html` 内 `BOOKS` 数组（国家书单）与 `READ/ENG/MATH/CALL/ART/TECHSPORT/MEDIA` 模板中的表格。
- **改打卡表提示**：`weekly-check.html` 内 `DATA` 对象与 `ROWS` 行定义（每科一句话摘要）。

## 六、交互与移动端适配（七个页面统一）

**站点头部（七页统一）**
- 站名 **起步线K12**，副标「家庭学习导航 · 小学到高中」；标志为绿底圆角方块 + 白色「起跑线」图形（一条竖向起跑线 + 三条向右延展的跑道线），并作为浏览器标签页图标。
- 顶部一条白底横栏：左侧标志 + 站名，右侧七项导航（学习规划 / 课程推荐 / 资料清单 / 教材目录 / 能力要求 / 赛事白名单 / 每周打卡），当前页高亮。
- 手机端导航收进「☰」抽屉：点开覆盖式下拉，选中即收起，点空白处也收起；打印时整条头部隐藏。
- 各页正文以「页名 + 一句话说明 + 提示条」开场（`.phead`），不再用面包屑按钮堆在标题下。

**今日打卡磁贴（index 顶部）**
- 手机打开第一屏就能看到「今天该做的 3–5 件小事」，不必按学科翻卡片。
- 取任务规则：语文 + 数学 + 英语 各取第 1 条为固定核心；3 年级以上加「体育与健康」；再按星期轮换 1 项课外（周一书法、周二编程、周三大阅读、周四英语拓展、周五戏曲、周六体育运动、周日科技）。
- 勾选与下方学科卡片**双向同步**（共用 `hub2|年级|学科|索引` 的 localStorage 键），并同步刷新本年级总进度；换年级自动换任务。


**减少滚动的手段**
- **吸顶导航**：`stickyhead` 把「页签 + 章节 chips」一起吸顶；手机端两行都可横向滑动，滚动时不占屏、不失联。
- **锚点直达**：courses / resources / standards 页由 JS 从卡片标题生成 chips（`#secnav`），点击即平滑滚到对应卡片并自动展开；`scroll-margin-top` 预留吸顶高度，标题不会被遮住。
- **卡片折叠**：index 在「全部学科」视图下 18 张卡默认折叠（只剩标题 + 一句话目标），点卡头或 chips 展开；单学科视图自动全展开，另有「全部展开/收起」。其余三页每张卡带「收起/展开」，章节 chips 右侧有全局开关。
- **书单筛选**：国家书单按学段拆成 3 张卡（3–4、5–6 默认折叠），每张卡内可再按 **全部 / 人文社科 / 文学 / 自然科学 / 艺术** 筛选，chips 上直接标数量（1–2 年级 3/12/4/2，合计 21）。
- **回到顶部**：五页右下角悬浮「↑」，滚动超过阈值才出现；打印时自动隐藏。

**移动端排版**
- **断点**：≤760px 视为手机；≤820px 的打卡表切换到可横向滑动模式。
- **导航**：桌面端 tab / chips 自动换行；手机端改为横向滑动、不换行、隐藏滚动条，吸顶区分隔线随滚动出现。
- **卡片**：手机端单列，内边距与字号收紧，任务行整行可点（`<label class="task-row">` 包住 checkbox，触控目标 ≥44px）；右上角固定「↑ 回顶」。
- **表格**：能力要求 / 课程页表格允许换行；资料清单四列宽表横向滑动且首列吸住；110 种书单在窄屏改为「书名 + 作者」卡片式列表（`table.books`）。
- **打印**：`weekly-check.html` 打印仍为 A4 横向一页（已用 Chrome print-to-pdf 校验为 1 页）；屏幕态独立于打印态，互不影响。

## 七、赛事白名单口径（competitions.html）
- **依据**：教育部办公厅《关于公布 2025—2028 学年面向中小学生的全国性竞赛活动的通知》（教监管厅函〔2025〕7 号，2025 年 10 月 22 日），共 47 项。
- **举办期**：原则上 2025 年 10 月—2028 年 8 月；每学年不超过 1 次，累计不超过 3 次。
- **红线**：竞赛及结果不得作为中小学招生入学依据，也不作为高考加分项目；名单外赛事不参加。
- **分类数量**：自然科学素养类 22 项、人文综合素养类 12 项、艺术体育类 13 项。
- **页面交互**：类别 tabs + 学段 chips 双重筛选，实时显示「当前显示 X / 47 项」；手机端表格转成卡片式（序号隐藏，主办与学段加前缀）。
- **报名路径**：全国校外教育培训监管与服务综合平台（xwpx.eduyun.cn）查报名时间与赛程 → 主办单位官网/公众号看当届通知 → 多数赛事由学校、青少年宫、科协统一组织。
- **防坑**：承诺「包获奖」「交钱保名额」「内部推荐」的一律排除；白名单赛事坚持公益属性，不得违规收费。
## 八、已知边界
- 纯静态，任务勾选进度存在本机浏览器 localStorage，换浏览器/清缓存会重置；不跨设备同步。
- 外链只挂长期稳定主域名，深链（具体课程页）易失效；打不开时按名称在官网重搜。
- 不存储、不转载第三方版权内容；付费课程建议先试听，书单以教材与正规出版社为主。
